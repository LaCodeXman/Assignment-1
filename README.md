# Executive Productivity Agent — Assignment 1

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local Streamlit URL shown in the terminal.

## Current UI

- Professional executive sidebar
- Executive profile image upload
- Overview dashboard
- Needs Attention workspace
- Commitment tracking and filtering
- Calendar
- Evidence/source viewer
- Ask the Agent

The prototype remains source-grounded and uses only the supplied Assignment 1 data.
